# 운영 보안 체크리스트

## 배포 전

- [ ] `src/config.js`에 비밀키, 개인 이메일, 실제 급여 데이터가 없는지 확인
- [ ] Firebase Authentication의 승인 도메인에 Pages 도메인만 추가
- [ ] Firestore를 테스트 모드로 운영하지 않음
- [ ] `firestore.rules`와 `firestore.indexes.json` 배포
- [ ] Storage는 사용 전까지 전면 차단 유지
- [ ] App Check 등록 후 요청 지표 확인 및 Firestore 적용 강제
- [ ] 관리자·선생님·미등록 계정으로 허용/거부 시나리오 확인
- [ ] 미등록 승인 요청에서 신규 선생님 문서·사용자 연결·승인 상태가 한 번에 저장되는지 확인
- [ ] 같은 이메일의 비활성 또는 이미 연결된 선생님이 있을 때 중복 신규 생성이 차단되는지 확인
- [ ] 선생님 비활성화 후 재로그인 차단 확인
- [ ] 선생님이 본인의 이름·연락처·생년월일·성별번호·보험 가입 여부·한 개/여러 개 시급만 수정할 수 있는지 확인
- [ ] 선생님의 이메일·UID·상태·근로소득 월급·보험 신고 기준액·기간·세금·공제 수정 시도가 거부되는지 확인
- [ ] 선생님이 본인의 미확정 월 수업시간만 저장하고 다른 선생님 또는 확정 월은 수정할 수 없는지 확인
- [ ] 선생님 제출 알림에는 급여액·연락처가 없고 본인 문서만 생성하며, 관리자만 조회·읽음 처리할 수 있는지 확인
- [ ] 가상 데이터로 급여 계산과 CSV/PDF 출력 검증
- [ ] 가상 급여 1차 발행, 확정 취소, 2차 재발행과 현재본 교체 확인
- [ ] 기장 회계사가 소득 구분, 요율, 상·하한, 반올림 규칙 확인

## 매월 마감

- [ ] 선생님별 보험 3종 가입·신고 기준액과 근로소득·사업소득 구분 확인
- [ ] 기본 근로소득, 기본/과목별 사업소득 시급과 이번 달 수업 시수 확인
- [ ] 사업소득 시급 × 수업 시수, 3.3% 공제액과 예상 지급액 확인
- [ ] 혼합 지급 선생님의 사업소득이 보험 기준액에서 제외되는지 확인
- [ ] 선생님 제출 시수와 관리자 등록 시급이 결합되고 알 수 없는 과목 ID는 계산에서 무시되는지 확인
- [ ] 수업이 없는 보험 가입자도 급여 대상에 포함되는지 확인
- [ ] 교통비·주차료·기타 지급의 처리 미확인 건이 없는지 확인
- [ ] 전체 주민등록번호가 앱·CSV·공개 저장소에 없고 생년월일·성별번호만 저장되는지 확인
- [ ] 생년월일·성별번호가 포함된 CSV를 공개 링크·개인 메일·공용 기기에 남기지 않음
- [ ] 보험 적용 기준액과 수동 공제 입력 근거 확인
- [ ] 적용 세금 기준의 공식 URL·시행일·버전과 간이세액표 확인
- [ ] 선생님별 공제대상가족 수·8~20세 자녀 수·원천징수 선택 비율 확인
- [ ] 선생님별 실 지급액 교차 검토
- [ ] 확정 전 기장 회계사 확인
- [ ] 확정 후 선생님 계정에서 본인 명세서만 보이는지 표본 확인
- [ ] 재발행 후 선생님에게 최신 차수만 보이고 과거 취소본은 관리자 이력에만 남는지 확인
- [ ] 교사 계정에서 본인 명세서 PDF만 다운로드되는지 확인
- [ ] Gmail API에 `gmail.send`만 요청하고 관리자 계정만 테스트 사용자로 등록했는지 확인
- [ ] 첨부 발송 전 수신자 이메일과 확정 월을 다시 확인
- [ ] 발송 이력에 OAuth 토큰이나 PDF 본문이 저장되지 않는지 확인
- [ ] 안내문 링크가 실제 Pages 주소를 가리키는지 확인
- [ ] 선생님 최초 열람 후 관리자 화면에 `열람 완료`가 표시되는지 확인
- [ ] 회계사 전달 파일을 공개 저장소·공용 기기에 남기지 않음
