# Academy Payroll Console 사용 설명서

이 문서는 관리자용 월별 급여 업무 순서입니다. 실제 개인정보를 입력하기 전에 테스트 Google 계정과 가상 급여로 전체 절차를 검증합니다.

## 1. 처음 시작하기

1. 관리자 Google 계정으로 로그인합니다.
2. Firebase 규칙, 색인, Storage 차단과 App Check 상태를 확인합니다.
3. 테스트 선생님으로 등록, 승인, 계산, 발행, 취소와 재발행을 시험합니다.
4. 시험이 끝난 뒤 실제 선생님 정보를 등록합니다.

공개 GitHub 저장소에는 이름, 이메일, 급여액, 계약서 같은 개인정보를 올리지 않습니다.

## 2. 선생님 등록과 계정 승인

1. `선생님 관리 > 선생님 등록`에서 이름과 Google 이메일, 급여·보험·세금 관련 정보를 입력합니다. 연락처, 주민등록번호 앞 생년월일 6자리와 뒷자리 첫 숫자 1자리, 담당 과목은 관리자가 입력하거나 비워 두고 선생님이 로그인 후 직접 입력할 수 있습니다. 전체 주민등록번호의 나머지 6자리는 입력하지 않습니다.
2. 선생님에게 포털 링크를 보내 처음 로그인하도록 안내합니다.
3. `Google 계정 승인 요청`에서 등록 이메일과 요청 이메일을 비교합니다.
4. 이메일이 정확히 일치할 때만 `계정 연결`을 승인합니다.
5. 퇴사한 선생님은 삭제하지 않고 비활성화합니다.

## 3. 선생님 정보와 수업시간 직접 입력

선생님은 `등록 정보 > 내 정보 수정`에서 이름, 연락처, 생년월일 6자리, 성별번호 1자리와 담당 과목을 직접 저장할 수 있습니다. Google 이메일, 계정 상태, 계약 조건, 지급일, 월급, 시급, 보험, 세금과 공제 정보는 표시된 입력 화면이나 브라우저 조작으로도 변경할 수 없도록 Firestore 규칙에서 관리자 전용으로 제한합니다.

선생님은 `수업시간 입력`에서 대상 월을 선택하고 근로소득 수업시간과 관리자가 등록한 사업소득 과목별 총 수업시간을 입력합니다. 저장하면 관리자에게 수업시간 제출 알림이 생성됩니다. 이 문서에는 월급이나 시급이 저장되지 않습니다. 급여 계산 때 관리자 시급과 선생님 제출 시수를 결합하고, 관리자가 검토·수정한 뒤 확정합니다. 확정된 월은 선생님과 관리자 모두 먼저 확정 취소 절차를 거치기 전에는 수업시간을 수정할 수 없습니다.

## 4. 보험·근로소득 월급·사업소득 시급

`선생님 관리`에서 국민연금, 건강보험·장기요양, 고용보험을 각각 선택하고 보험별 신고 기준액과 적용 기간을 입력합니다. 세 보험은 한 번에 선택할 필요가 없고 선생님의 실제 가입 상태에 맞게 따로 관리합니다.

기본 근로소득 월급과 과목별 사업소득 시급도 함께 입력합니다. 과목마다 시급이 다르면 `시급 추가`로 여러 줄을 등록합니다. 같은 선생님에게 근로소득 월급과 사업소득 시급을 동시에 설정할 수 있습니다. 소득 구분은 계약서 명칭만 보지 말고 회계사·노무사와 실제 고용관계를 확인합니다.

## 5. 월 급여 입력

1. `월 급여 입력`에서 급여월을 선택합니다.
2. 상단 종 아이콘의 수업시간 제출 알림을 누르면 해당 선생님과 급여월의 월 지급액 입력 창이 바로 열립니다.
3. 각 선생님의 보험별 가입·신고 기준액, 기본 근로소득과 등록된 사업소득 시급을 확인합니다.
4. 선생님이 제출한 근로 수업시간과 과목별 사업소득 수업 시수를 확인하고 누락이나 오류가 있으면 수정합니다.
5. 국민연금·건강보험·고용보험의 이번 달 신고 기준액을 각각 확인합니다.
6. 대중교통 이용 횟수와 1회 금액, 주차료, 기타 지급 항목을 입력합니다.
7. 교통비·주차료·기타 지급마다 `사업소득 3.3%`, `근로소득 과세`, `비과세 실비`, `기타소득` 중 세무사가 확인한 처리를 선택합니다. 아직 확인 전이면 `처리 미확인`으로 두되 급여를 확정할 수는 없습니다.
8. 화면에서 `시급 × 수업 시수`, 강사료 총액, 예상 3.3%와 신고액을 확인합니다.
9. 보험 가입 선생님의 근로소득 월급이 빠지지 않았는지 확인합니다.

사업소득 계산에는 입력한 수업 시수를 사용하지만 근로소득 월급에는 수업 여부가 영향을 주지 않습니다. 보험 가입자는 수업이 없어도 기본 월급이 자동 적용됩니다.

급여가 확정된 월은 잠기며, 수정하려면 먼저 확정 취소 사유를 기록해야 합니다.

## 6. 급여 계산과 공제

`급여 대시보드`에서 총 지급액, 공제액과 실 지급액을 확인합니다. 선생님 행의 계산기 아이콘에서 공제 조정을 열 수 있습니다. 자동 사회보험료는 예상값이므로 공단 고지액, 입·퇴사월, 두루누리, 휴직과 정산 내역을 확인한 뒤 국민연금, 건강보험+장기요양 합계, 고용보험의 수동 공제액으로 맞춥니다.

## 7. 급여 확정·취소·재발행

1. 회계사 검토가 끝나면 `급여 확정`을 누릅니다.
2. 확정 즉시 현재 명세서가 선생님에게 공개됩니다.
3. 오류가 있으면 `확정 취소`에서 개인정보 없는 사유를 기록합니다.
4. 월 지급액 또는 공제액을 수정한 뒤 `수정본 재발행`을 누릅니다.
5. 이전 차수와 취소 이력은 관리자 기록에 보존됩니다.

## 8. 개인 급여명세서 출력과 이메일

1. `급여 대시보드`에서 급여월을 선택합니다.
2. 선생님별 급여 표 맨 오른쪽의 `명세서 보기` 아이콘을 누릅니다.
3. 개인 명세서 상단에서 `PDF 다운로드` 또는 `인쇄`를 사용합니다.
4. 급여 확정 후 `이메일 발송`을 눌러 수신자와 첨부 파일을 확인합니다.
5. Gmail API를 사용하지 않으면 `PDF 저장 후 메일 앱 열기`로 직접 첨부합니다.

## 9. 월별 급여내역서

`월별 급여내역서`에서 신고액, 수업시간, 강사료와 3.3%, 교통 횟수·교통비·주차료·기타, 추가 지급 원천징수, 근로소득세·지방소득세, 건강+요양·국민연금·고용보험과 각 신고 기준액을 확인합니다. 인쇄하거나 CSV로 내려받아 회계사와 합의한 안전한 채널로 직접 전달합니다.

CSV에는 회계 확인용 `생년월일 6자리-성별번호 1자리`가 포함되지만 전체 주민등록번호는 없습니다. CSV도 개인정보 문서이므로 회계사와 합의한 안전한 채널로만 전달하고 공개 GitHub 저장소에는 올리지 않습니다.

## 10. 계산·보안 설정

세금과 사회보험 기준이 바뀌면 과거 버전을 수정하지 않고 새 시행일의 버전을 추가합니다. 공식 근거, Firestore 규칙, 복합 색인, Storage 차단과 App Check 적용 상태를 정기적으로 확인합니다.

## 11. AI 도움말

관리자 화면 왼쪽 아래의 `AI 도움말`을 누르면 어느 탭에서든 사용법을 질문할 수 있습니다. Gemini가 설정되기 전에도 내장 설명서를 검색해 답합니다.

AI 도움말에는 실제 이름, 이메일, 전화번호, 주민등록번호, 생년월일·성별번호, 계좌번호와 급여액을 입력하지 않습니다. 챗봇은 사용법 안내만 담당하며 급여 계산, 데이터 수정, 확정 또는 발송 작업을 직접 수행하지 않습니다.

## 12. 문제 해결

- 로그인이 안 되면 Google 로그인 제공업체와 승인 도메인을 확인합니다.
- 승인 요청이 연결되지 않으면 등록 이메일과 로그인 이메일을 비교합니다.
- 명세서가 보이지 않으면 대상 월의 급여 확정 상태를 확인합니다.
- 이메일 버튼이 비활성화되면 급여가 확정됐는지 확인합니다.
- Gmail 오류가 발생하면 Gmail API와 OAuth 범위를 확인하거나 PDF 직접 첨부 방식을 사용합니다.
